JHALAK LOVE NOTE — QUICK SETUP

1. Make a NEW GitHub repository, e.g. jhalak-love-note.
2. Upload index.html to the root of the repository.
3. Upload your song file named exactly: Pyar Ki Si.mp3 (same folder as index.html).
   If its filename differs, edit the <source src="Pyar%20Ki%20Si.mp3"...> line in index.html.
4. On GitHub, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Your site will be at https://YOUR-USERNAME.github.io/jhalak-love-note/

Edit the text directly in index.html. The countdown automatically targets the next November 17.
This is a separate website and won't replace your birthday website.
